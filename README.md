# Video Cutter Studio v0.6.0

Windows向けのシンプルな動画編集デスクトップアプリです。

インストーラー版は Python / Tkinter をベースに、PyInstaller + Inno Setup で配布しています。

Python版のソースコードは、GitHub ReleasesのPython版ZIPに含まれています。

## 1. 動作環境

### インストーラー版

* Windows 10 / 11（64bit）
* インストーラー（Setup.exe）を実行するだけで利用できます。
* 別途 Python や FFmpeg をインストールする必要はありません。

### Python版

* Windows
* Python 3.x
* Python版では、必要なPythonライブラリをインストールして実行してください。

## 2. 主な機能

* 動画 / 画像 / 音楽のインポートとタイムライン編集
* 字幕、図形、エフェクト、画面切り替え、シーンの追加
* キーフレームアニメーション
* 動画・音楽クリップの速度コントロール（25%〜400%、ピッチ保持対応）
* オーディオダッキング
* 左右バランス（パン）、ミュート、簡易ノイズ軽減
* 音声フェードイン / フェードアウト
* マルチカムの簡易切り替え
* クリップのカラーラベル
* 字幕のSRT一括インポート / エクスポート
* 数値指定での正確な区間カット、無音検出、リップル削除
* 元に戻す / やり直す（最大30ステップ）
* グループ化、テンプレート保存・適用
* レイアウトプリセット
* 書き出し設定プリセット
* 書き出しキュー
* 書き出し中のキャンセル、空き容量の事前チェック
* 素材の再リンク
* プロジェクトファイル（.vcs）の自動バックアップ・復元
* 最近のプロジェクトのサムネイル表示
* 自動保存（3分ごと）

## 3. Python版

Python版は `video_cutter_studio.py` としてGitHub ReleasesのPython版ZIPで公開しています。

Python版を使用する場合は、Pythonをインストールした環境で必要なライブラリをインストールしてください。

### 必要なライブラリ

```text
pillow
opencv-python
numpy
pygame
imageio-ffmpeg
librosa
```

### 起動方法

```bash
python video_cutter_studio.py
```

Python版はインストーラー版とは別のビルドとして提供しています。

バージョンや機能、動作仕様などがインストーラー版と異なる場合があります。

## 4. インストーラー版の起動方法

デスクトップまたはスタートメニューの「Video Cutter Studio」から起動してください。

## 5. データの保存場所

プロジェクトファイル（`.vcs`）は保存時に選んだ任意の場所に保存されます。

以下のアプリ内データはユーザーフォルダ配下の `.video_cutter_studio` フォルダに自動保存されます。

例:

```text
C:\Users\ユーザー名\.video_cutter_studio
```

主な保存データ:

* テンプレート、最近使ったファイル・プロジェクトの履歴
* レイアウトプリセット、書き出し設定プリセット
* 最近のプロジェクトのサムネイル画像
* 自動保存ファイル
* バックアップ
* クラッシュログ

## 6. FFmpegのライセンスとソースコード

Video Cutter Studioのインストーラー版では、`imageio-ffmpeg` から提供されるLGPLライセンスのFFmpegバイナリを使用しています。

FFmpegのライセンス全文は `LICENSES/FFmpeg-LGPL-2.1.txt` に同梱しています。

FFmpegの対応するソースコードについては、使用している `imageio-ffmpeg` の配布元およびFFmpeg公式のソース配布物を確認してください。

配布物に含まれるFFmpegバイナリのバージョン情報から、使用されているFFmpegのバージョンを確認できます。

FFmpegは本アプリ独自ライセンスの対象ではなく、該当するLGPLの条件が優先して適用されます。

詳細は `THIRD-PARTY-LICENSES.txt` を参照してください。

FFmpeg公式サイト:

https://ffmpeg.org/

## 7. 注意事項

* 書き出しにはある程度の時間がかかります。書き出し中はキャンセルボタンで中断できます。
* 書き出し前に空き容量が不足している可能性がある場合は警告が表示されますが、続行するかどうかはご自身で判断してください。
* 書き出しキューでの連続実行時は、空き容量の警告は表示されません。
* 速度コントロールで「ピッチを保持」を使う場合、処理に時間がかかることがあります。
* マルチカム切替は、再生ヘッド位置で2つ以上の動画クリップが重なっている場合にのみ利用できます。
* Python版では、使用するPython環境やライブラリの状態によって動作が異なる場合があります。

## 8. 主なキー操作

| キー                 | 動作                     |
| ------------------ | ---------------------- |
| Space              | 再生 / 一時停止              |
| Delete / BackSpace | 選択中のアイテム（またはキーフレーム）を削除 |
| Ctrl + S           | プロジェクトを保存              |
| Ctrl + O           | プロジェクトを開く              |
| Ctrl + Z           | 元に戻す                   |
| Ctrl + Y           | やり直す                   |
| ,（コンマ）             | 前へ1コマ送り                |
| .（ピリオド）            | 次へ1コマ送り                |
| Shift + , / .      | 前後へ10コマ送り              |
| Ctrl + ホイール        | タイムラインをカーソル位置中心にズーム    |
| Shift + クリック       | タイムライン上で複数アイテムを選択      |

メニュー「その他 > ショートカット一覧」からアプリ内でも確認できます。

## 9. FFmpegについて

VideoCutterStudioでは、動画・音声の処理にFFmpegを使用しています。

配布版には、`imageio-ffmpeg` を通じて取得・同梱されたFFmpegバイナリが含まれます。

FFmpegにはLGPL-2.1-or-laterが適用されます。対応するライセンス本文は以下に収録しています。

`LICENSES/FFmpeg-LGPL-2.1.txt`

FFmpegおよびその他の第三者コンポーネントについては、それぞれに適用されるライセンス条件が優先されます。詳細は `THIRD-PARTY-LICENSES.txt` を確認してください。

なお、実際に配布されるFFmpegバイナリに適用されるライセンス条件については、同梱されるFFmpegのライセンス表示および対応する第三者ライセンス情報を確認してください。
