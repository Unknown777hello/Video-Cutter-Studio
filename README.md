# Video Cutter Studio v0.2beta

タイムラインで切って、貼って、動かす。自作のWindows向け動画編集ソフトです。

## 1. 動作環境

- Windows 10 / 11
- インストーラー（Setup.exe）を実行するだけで利用でき、Python本体や追加ライブラリを別途インストールする必要はありません

## 2. 主な機能一覧

- **タイムライン編集**: 動画・画像・音楽のインポート、可変トラック、ドラッグ移動・リサイズ
- **字幕・図形・エフェクト・画面切り替え・シーンアイテム**: プレビュー・書き出しの両方に反映
- **キーフレームアニメーション（v0.2beta 新機能）**: 図形・字幕は位置/スケール/回転/不透明度、エフェクトは強さを、リニア/イーズイン/イーズアウトで補間しながらアニメーションさせられます
- **速度コントロール強化（v0.2beta 新機能）**: クリップ全体の速度を25%〜400%で一律変更でき、「ピッチを保持」オプション（librosa使用）で音程を保ったまま速度だけ変更できます
- **字幕自動生成（v0.2beta ベータ・スタブ）**: メニューは用意済み、実際の音声認識は今後実装予定
- **カット編集支援**: リップル削除・全トラック左詰め・無音部分の検出と削除
- **実データに基づく音声波形表示**
- **グループ化 / Undo・Redo / テンプレート / レイアウトプリセット**
- **MP4 / MOV / AVI 書き出し**: 映像・音声・字幕・エフェクトを含めて書き出し

## 3. 起動方法

1. インストーラー（Setup.exe）を実行し、画面の指示に従ってインストールする
2. スタートメニューまたはデスクトップのショートカットから「Video Cutter Studio」を起動する
3. ホーム画面から「新しいプロジェクト」または「プロジェクトを開く」を選ぶ

## 4. データの保存場所

```
~/.video_cutter_studio/
    templates.json        テンプレート
    recent.json            最近使ったファイル / プロジェクト
    custom_layouts.json    カスタムレイアウトプリセット
    crash_log.txt          クラッシュログ
    backups/                プロジェクトの自動バックアップ
```

## 5. 注意事項

- プレビュー画面上のキーフレーム不透明度アニメーションは、Tkinter Canvasの制約により背景色との合成で近似表示されます（書き出し映像は正確なアルファ合成になります）。
- 速度コントロールの「ピッチを保持」は、プレビュー再生では処理負荷の都合上、簡易処理（音程が変化する）で近似されます。正確なピッチ保持は動画書き出し時にのみ適用されます。
- 字幕自動生成は現時点ではスタブであり、実際の音声認識は行われません。
- exe化（PyInstaller）する場合、librosaの追加により配布サイズが増加します。

## 6. 主なキー操作

| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| Delete / BackSpace | 選択中アイテムの削除 |
| Ctrl+S | プロジェクトを保存 |
| Ctrl+O | プロジェクトを開く |
| Ctrl+Z | 元に戻す |
| Ctrl+Y | やり直す |
| Shift+クリック | 複数選択（グループ化用） |
