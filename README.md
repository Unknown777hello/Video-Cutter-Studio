# Video Cutter Studio v0.6.0

Windows向けのシンプルな動画編集デスクトップアプリです。Python / Tkinter
のみで実装されており、PyInstaller + Inno Setup でインストーラー配布
しています。

## 1. 動作環境

- Windows 10 / 11（64bit）
- インストーラー（Setup.exe）を実行するだけで利用できます。別途 Python
  や ffmpeg をインストールする必要はありません。

## 2. 主な機能一覧

- 動画 / 画像 / 音楽のインポートとタイムライン編集
- 字幕、図形、エフェクト、画面切り替え、シーンの追加
- キーフレームアニメーション（位置・スケール・回転・不透明度・強さ）
  - 補間方式: リニア / イーズイン / イーズアウト / イーズインアウト /
    キュービック / ホールド / ベジェ
  - **NEW:** キーフレームのコピー / 貼り付け（アイテム間で動きを複製）
- 動画・音楽クリップの速度コントロール（25%〜400%、ピッチ保持対応）
- オーディオダッキング（特定クリップ再生中に他トラックの音量を自動で下げる）
- 左右バランス（パン）・ミュート・簡易ノイズ軽減
- **NEW:** 音声フェードイン / フェードアウトの数値指定
- **NEW:** マルチカムの簡易切り替え（重なっている動画クリップを巡回表示）
- クリップのカラーラベル（8色、タイムライン上での分類表示）
- 字幕のSRT一括インポート／エクスポート
- 数値指定での正確な区間カット、無音検出、リップル削除
- 元に戻す／やり直す（最大30ステップ）
- グループ化、テンプレート保存・適用
- レイアウトプリセット（4種類＋カスタム保存）
- 書き出し設定プリセットの保存（解像度・FPS・コーデック・ビットレート）
- **NEW:** 書き出しキュー（複数の出力設定をまとめてバッチ書き出し）
- 書き出し中のキャンセル、空き容量の事前チェック
- 素材の再リンク（見つからないファイルの再検索）
- プロジェクトファイル（.vcs）の自動バックアップ・復元
- **NEW:** 最近のプロジェクトのサムネイル表示（ホーム画面）
- 自動保存（3分ごと）、ショートカット一覧の確認

## 3. 起動方法

デスクトップまたはスタートメニューの「Video Cutter Studio」から起動して
ください。

## 4. データの保存場所

プロジェクトファイル（`.vcs`）は保存時に選んだ任意の場所に保存されます。
以下のアプリ内データはユーザーフォルダ配下の `.video_cutter_studio`
フォルダに自動保存されます（例: `C:\Users\ユーザー名\.video_cutter_studio`）。

- テンプレート、最近使ったファイル・プロジェクトの履歴
- レイアウトプリセット、書き出し設定プリセット
- 最近のプロジェクトのサムネイル画像（`project_thumbs` フォルダ）
- 自動保存ファイル、バックアップ、クラッシュログ

## 5. 注意事項

- 書き出しにはある程度の時間がかかります。書き出し中はキャンセルボタン
  で中断できます。
- 書き出し前に空き容量が不足している可能性がある場合は警告が表示され
  ますが、続行するかどうかはご自身で判断してください（書き出しキュー
  での連続実行時はこの警告は表示されません）。
- 速度コントロールで「ピッチを保持」を使う場合、処理に時間がかかること
  があります。
- マルチカム切替は、再生ヘッド位置で2つ以上の動画クリップが重なって
  いる場合にのみ利用できます。

## 6. 主なキー操作

| キー | 動作 |
| --- | --- |
| Space | 再生 / 一時停止 |
| Delete / BackSpace | 選択中のアイテム（またはキーフレーム）を削除 |
| Ctrl + S | プロジェクトを保存 |
| Ctrl + O | プロジェクトを開く |
| Ctrl + Z | 元に戻す |
| Ctrl + Y | やり直す |
| , （コンマ） | 前へ1コマ送り |
| . （ピリオド） | 次へ1コマ送り |
| Shift + , / . | 前後へ10コマ送り |
| Ctrl + ホイール | タイムラインをカーソル位置中心にズーム |
| Shift + クリック | タイムライン上で複数アイテムを選択 |

メニュー「その他 > ショートカット一覧」からアプリ内でも確認できます。
