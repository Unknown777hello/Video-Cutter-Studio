# Video Cutter Studio v0.2
Windowsデスクトップ向けの動画編集アプリです。インストーラー1つで、Pythonの知識がなくても動画編集を始められます。

## 1. 動作環境
- Windows 10 / 11（64bit）
- Setup.exe から通常のWindowsアプリと同じ手順でインストールできます。Pythonのインストールなど追加の準備は不要です。

## 2. 主な機能一覧
- 動画 / 画像 / 音楽の読み込みとタイムライン編集
- 字幕（縁取り・影・背景・配置プリセット・キーフレームアニメーション対応）
- 図形アイテム（四角形・楕円・三角形・星形）
- エフェクト（クロスディゾルブ・グリッチ・ブラー など11種類）
- 画面切り替え（ディゾルブ・ワイプ・アイリス など11種類）
- シーンアイテム / シーンタブ
- 音声編集: 音量・左右バランス・ミュート・ノイズ軽減・音量フェードイン/アウト
- 速度コントロール（ピッチ保持オプション付き）
- タイムラインのスナップ（Altキーで一時解除）・グリッド表示
- オートセーブ（3分間隔）とホーム画面からの復元
- 元に戻す / やり直す（最大30ステップ）
- MP4 / MOV / AVI書き出し（解像度・FPS・音声サンプリングレート・動画コーデック(H.264/H.265)・ビットレートを指定可能）
- プロジェクト管理（最近のプロジェクト・テンプレート・バックアップをまとめて確認・操作できるダイアログ）

## 3. 起動方法
インストール後、デスクトップまたはスタートメニューの「Video Cutter Studio」を選択してください。起動するとスプラッシュ画面のあとホーム画面が表示され、「新しいプロジェクト」または「プロジェクトを開く」から編集を始められます。

## 4. データの保存場所
- プロジェクトファイル（`.vcs`）: 保存先はユーザーが指定
- 自動保存: `%USERPROFILE%\.video_cutter_studio\autosave.vcs`
- バックアップ: `%USERPROFILE%\.video_cutter_studio\backups\`（保存の都度自動作成、最新15件を保持）
- テンプレート / 最近使ったファイル / レイアウト設定なども同じく `%USERPROFILE%\.video_cutter_studio\` 以下に保存

## 5. 注意事項
- 書き出し設定でH.265コーデックを選択した場合、再生には対応したプレイヤーが必要です。互換性を重視する場合はH.264を選択してください。
- ノイズ軽減は簡易的なノイズゲート方式のため、強いノイズを完全に除去するものではありません。強さを上げすぎると小さな声や音も一緒に減衰する場合があります。
- AVI書き出しは互換性のためコーデックがmpeg4固定です（ビットレート指定のみ反映されます）。

## 6. 主なキー操作
| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| Delete / BackSpace | 選択中のアイテム（またはキーフレーム）を削除 |
| Ctrl+S | プロジェクトを保存 |
| Ctrl+O | プロジェクトを開く |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| Ctrl+ホイール | タイムラインをカーソル位置基準でズーム |
