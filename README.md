# Video Cutter Studio v0.5.0

Windows向けの自作デスクトップ動画編集アプリです。Python / Tkinter製の単一ファイルアプリケーションを PyInstaller + Inno Setup でスタンドアロンのWindowsインストーラーとして配布しています。

v0.5では、クリップのカラーラベル、オーディオダッキング、書き出しプリセットの保存、字幕のSRT一括インポート／エクスポート、素材の再リンク、プロジェクトファイルのマイグレーション機構、キーフレーム補間カーブの追加などを実装しました。

## 1. 動作環境

- Windows 10 / 11（64bit）
- インストーラー（Setup.exe）を実行するだけで利用できます。追加のランタイムのインストールは不要です。

## 2. 主な機能一覧

- 動画 / 画像 / 音楽のタイムライン編集（複数トラック対応）
- 字幕、図形、エフェクト（11種類）、画面切り替え（11種類）、シーン管理
- キーフレームアニメーション（7種類の補間カーブに対応）
- 速度コントロール（25%〜400%、librosaによるピッチ保持対応）
- オーディオダッキング、左右バランス、ミュート、簡易ノイズ軽減
- クリップのカラーラベル
- 字幕のSRT一括インポート／エクスポート
- 数値指定での正確な区間カット、無音検出＋削除、リップル削除
- 元に戻す／やり直す（最大30ステップ）
- グループ化、テンプレートの保存・適用・共有（.json）
- レイアウトプリセット（組み込み4種類＋カスタム保存）
- 書き出し設定プリセットの保存、書き出し中のキャンセル、空き容量チェック
- 素材の再リンク（欠落ファイルの個別選択・フォルダ一括再検索）
- プロジェクトファイル（.vcs）の自動バックアップ・復元、自動保存
- プロジェクトファイルのマイグレーション機構（VCS_VERSION管理）

## 3. 起動方法

インストール後、デスクトップまたはスタートメニューの「Video Cutter Studio」から起動してください。

## 4. データの保存場所

プロジェクトファイル（`.vcs`）は保存時に選択した任意の場所に保存されます。テンプレート・レイアウトプリセット・書き出し設定プリセット・履歴・自動保存・バックアップなどのアプリ内データは `%USERPROFILE%\.video_cutter_studio\` 配下に保存されます。

## 5. 注意事項

- 書き出しには時間がかかる場合があります。進捗ダイアログの「キャンセル」でいつでも中断できます。
- 書き出し前に空き容量が不足している可能性がある場合は警告が表示されます（自動的には中止しません）。
- ピッチ保持付きの速度変更は librosa によるフェーズボコーダ処理のため、書き出し時に時間がかかることがあります。

## 6. 主なキー操作

| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| Delete / BackSpace | 選択中のアイテム（キーフレーム）を削除 |
| Ctrl+S | プロジェクトを保存 |
| Ctrl+O | プロジェクトを開く |
| Ctrl+Z | 元に戻す |
| Ctrl+Y / Ctrl+Shift+Z | やり直す |
| , / . | 前後へ1コマ送り |
| Shift+, / Shift+. | 前後へ10コマ送り |
| Ctrl+ホイール | タイムラインズーム（カーソル中心） |
| Shift+クリック | 複数アイテム選択 |
