# Video Cutter Studio v0.1

Python/Tkinter製の無料デスクトップ動画編集アプリです。

## 1. 動作環境

- OS: Windows 10 / 11（推奨）
- Python: 3.9 以降
- 必要ライブラリ: pillow, opencv-python, numpy, pygame, imageio-ffmpeg
- 追加のffmpegインストールは不要です（imageio-ffmpeg同梱のffmpegを使用）

## 2. 主な機能一覧

- **タイムライン編集**: 可変トラック数、ドラッグ移動、端リサイズ、グループ化
- **音声波形の実データ表示**: 動画埋め込み音声・音楽クリップの実際の音声データから波形を生成し、音量の大きい部分やセリフの位置、音楽のビートを視覚的に確認できます
- **カット編集支援**: リップル削除、全トラックを左詰め、無音部分の検出（確認のうえ削除）
- **字幕・図形・エフェクト・画面切り替え・シーンアイテム**: プレビュー・書き出しの両方に反映
- **元に戻す・やり直す**: 最大30ステップのUndo/Redo
- **レイアウトプリセット**: 4種類の組み込みレイアウト＋カスタム保存
- **ピークメータ・ラウドネスメータ・専用メータダイアログ**: 再生中の音量をリアルタイムに確認
- **MP4/MOV/AVI書き出し**: 音声込みでH.264エンコード書き出し
- **プロジェクト保存/読み込み**: 独自拡張子 .vcs（JSON形式）

## 3. 起動方法

1. 依存ライブラリをインストールします
   ```
   pip install pillow opencv-python numpy pygame imageio-ffmpeg
   ```
2. 以下のコマンドでアプリを起動します
   ```
   python video_cutter_studio.py
   ```
3. スプラッシュ画面のあと表示されるホーム画面から「新しいプロジェクト」または「プロジェクトを開く」を選びます

## 4. データの保存場所

```
~/.video_cutter_studio/
├── recent.json          最近使ったファイル・プロジェクト
├── templates.json        保存済みテンプレート
├── custom_layouts.json    カスタムレイアウトプリセット
├── crash_log.txt          未捕捉例外のクラッシュログ
└── backups/               プロジェクト保存時の自動バックアップ（最新15件）
```

## 5. 注意事項

- 音声波形の解析にはある程度の時間がかかる場合があります（初回のみ、以降はキャッシュされます）
- 無音部分の検出は自動削除を行いません。必ず一覧を確認してから削除してください
- ロックしたトラックのクリップは移動・リサイズできません

## 6. 主なキー操作

| キー          | 動作                     |
|---------------|--------------------------|
| Space         | 再生 / 一時停止           |
| Delete / BackSpace | 選択中のアイテムを削除 |
| Ctrl+S        | プロジェクトを保存         |
| Ctrl+O        | プロジェクトを開く         |
| Ctrl+Z        | 元に戻す                  |
| Ctrl+Y        | やり直す                  |
