# Video Cutter Studio v0.4.0

Windowsデスクトップ向けの動画編集アプリです。Python / Tkinter製の単一
ファイルアプリケーションとして開発しており、PyInstaller + Inno Setup で
Windows用インストーラーを作成しています。

v0.4では、数値指定での正確な区間カット・複数区間一括カット、字幕の表示
時間専用UI、フレーム単位のコマ送り操作を追加しました。あわせてシークの
高速化・フレームのLRUキャッシュ化によるメモリ削減・書き出し失敗時の
エラー表示改善など、編集操作の快適さと安定性を高めています。

## 1. 動作環境
- Windows 10 / 11（64bit）
- インストーラーから導入すれば、Python等の追加インストールは不要です

## 2. 主な機能一覧
- タイムライン編集（複数トラック・ドラッグ移動・端リサイズ・スナップ・
  グループ化・元に戻す/やり直す）
- プレビュー再生（再生/一時停止/停止/ループ・シークバー・フレーム単位の
  コマ送り）
- カット編集（分割・リップル削除・全トラック左詰め・無音検出・数値指定
  での正確な区間カット/複数区間一括カット）
- 字幕（フォント・太字/斜体・色・配置・縁取り・影・背景ボックス・
  表示時間・キーフレームアニメーション）
- 図形・エフェクト（11種類）・画面切り替え（11種類）・シーンバナー
- 音声編集（音量・ミュート・左右バランス・簡易ノイズ軽減・速度
  コントロール/ピッチ保持）
- 書き出し（MP4/MOV/AVI・H.264/H.265・ビットレート指定・進捗表示・
  キャンセル・空き容量チェック・分かりやすいエラー表示）
- プロジェクト保存（原子的保存・オートセーブ・バックアップ復元）

## 3. 起動方法
インストーラー（Setup.exe）を実行し、案内に従ってインストールしてください。
インストール後はデスクトップ/スタートメニューのショートカットから起動
できます。

## 4. データの保存場所
設定・テンプレート・バックアップ等は `%USERPROFILE%\.video_cutter_studio\`
に保存されます。

## 5. 注意事項
- 大きな動画ファイルを扱う場合、PCの性能によっては動作が重くなることが
  あります。
- プロジェクトファイル（`.vcs`）は独自形式です。

## 6. 主なキー操作
| キー | 動作 |
|---|---|
| Space | 再生 / 一時停止 |
| , / . | 前へ1コマ / 次へ1コマ |
| Shift+, / Shift+. | 前へ10コマ / 次へ10コマ |
| Delete / BackSpace | 選択中のアイテムを削除 |
| Ctrl+S | プロジェクトを保存 |
| Ctrl+O | プロジェクトを開く |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
