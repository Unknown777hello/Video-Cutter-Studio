# Windows向け動画編集ソフト「Video Cutter Studio」v0.1beta

タイムラインでサクッと動画を切って字幕やエフェクトを乗せたい――そんな時に使える、Windows向けの軽量な動画編集ソフトが **Video Cutter Studio** です。

## 動作環境

- Windows 10 / Windows 11 (64bit)
- 追加のソフトウェアのインストールは不要（インストーラーに必要なファイルがすべて含まれています）

## 主な機能

### 🎬 可変トラック数のタイムライン編集
ドラッグでの移動・端をつまんでのリサイズ・赤い線（再生ヘッド）の位置でのクリップ分割に対応。トラックごとに表示/非表示・ロックの切り替えもできます。

### 🧩 豊富なアイテム種別
動画・画像・音楽・字幕に加えて、以下をタイムラインに配置できます。

- 図形（四角形 / 楕円 / 三角形 / 星形）
- エフェクト（クロスディゾルブ、グリッチ、ライトリーク、ズームイン/アウト、ワイプ、クロマキー合成、ブラー、カラーグレーディング、スピードランプ、ドロップシャドウ、の11種類）
- 画面切り替え（フェードイン/アウト、ディゾルブ、ワイプ、スライド、ズーム、フリップ、ページターン、クロスズーム、アイリス、フラッシュ、の11種類）
- シーンアイテム（オープニング／回想／アクション等、種類ごとに色分け表示）

### 📝 字幕編集
フォント・太字/斜体・文字色・配置・X/Y座標・スケール・回転・不透明度・アニメーションまで細かく調整可能です。

### ↩️ グループ化・元に戻す/やり直す
複数アイテムをグループ化してまとめて移動、ほぼ全ての編集操作をUndo/Redo（最大30ステップ）できます。

### 📤 書き出し
- MP4 / MOV / AVI に対応
- 解像度・FPS・音声サンプリングレートをステータスバーから変更可能（既定はフルHD 1920×1080）
- 映像・音声（動画埋め込み音声/音楽クリップのミックス）を正しいタイミングで書き出し

### 🔊 音声レベルの可視化（v0.1beta）
プレビュー横にピーク/ラウドネスメータを常時表示できるほか、メニュー「メータ」からラウドネス/ピーク/L/Rメータの専用ダイアログを開き、現在値（dB）と簡易な時系列グラフで音の大きさを確認できます。

### 🛠 そのほか
レイアウトプリセット（4種類＋カスタム保存）、テンプレート機能、最近使ったファイル/プロジェクト、バックアップからの復元、クラッシュログの自動記録、GitHub連携のバージョン確認、UIの拡大率変更など、実務で使える機能を備えています。

## v0.1beta での変更点

### 新機能
- メニューバーに **「メータ」** を新設。ラウドネスメータ / ピークメータ / Lメータ / Rメータの4項目があり、選択すると専用ダイアログが開きます。現在の音量（dB表示）と直近の推移を示す時系列グラフを確認できます。L/Rメータでは、これまでプレビュー横のメータ帯では見られなかった左右チャンネルそれぞれのピークレベルを独立して確認できます。

### 不具合修正
- 設定ダイアログの「閉じる」ボタンが見切れる不具合を修正（ダイアログの内容量に応じて高さを自動調整）
- ツールバーのピーク/ラウドネスメータ表示ボタンのアイコンが見切れる不具合を修正
- メータのグラフ表示（ラウドネス/ピーク/L/Rメータ）を複数同時に開くと重くなる不具合を修正（音声レベル計算を1回にまとめ、グラフ再描画も座標更新のみに変更）

## 起動方法

1. インストーラーを実行し、画面の指示に従ってインストールしてください。
2. インストール完了後、デスクトップまたはスタートメニューの「Video Cutter Studio」アイコンから起動します。

## データの保存場所

以下のフォルダにアプリの設定・テンプレート・バックアップ等が保存されます。

```
%USERPROFILE%\.video_cutter_studio\
```

| ファイル/フォルダ | 内容 |
|---|---|
| `settings.json` / `recent.json` / `templates.json` / `custom_layouts.json` | 各種設定・履歴 |
| `backups\` | プロジェクトの自動バックアップ（最新15件） |
| `crash_log.txt` | クラッシュログ |

## まとめ

Video Cutter Studio v0.1beta は、タイムライン編集から字幕・図形・エフェクト・画面切り替え、音声レベルの可視化まで、動画編集に必要な機能を1本にまとめたソフトです。インストール後すぐに使い始められるので、ぜひ一度試してみてください。
